# End-of-ROM index census: how far the read watch reached

Generated by `tools/research/endrom_index_census.py`; `--check` re-derives this page from
`docs/research/RUNTIME_READ_RUNS.csv` and `docs/research/RUNTIME_READ_ROW_HITS.csv`.

## What was run

* The watch is the read-logging runtime outside this repository, driven headless by
  `tools/runtime/recomp_read_sweep.py`: one CSV line per ROM read, `pc,lr,addr,width,frame`.
* The watched ranges are the three rows below in full, plus the liveness range the driver
  appends (`0x08e2e0..0x08e2f0`).
* One run per map: the saved game's `map:0038/transition:0000` record is retargeted in a
  private ROM copy, so the engine's own key resolver and loader load the requested map.
* 102 runs over map 2..450, one per map; 98 confirmed the arrival map and 102 carry the
  liveness read at `pc 0x08008a0e`, whose count proves the read channel was open in that run.
  Every run's digest, arrival and liveness count is the `endrom-warp` row of
  `docs/research/RUNTIME_READ_RUNS.csv`.
* The method's ceiling: a session reaches indices, and the highest index it reaches is a
  lower bound. No run states a count.
