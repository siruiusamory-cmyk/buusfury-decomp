# Friend v3 playtest: chapter checkpoints

The long version of `FRIEND_V3_PLAYTEST_GUIDE.md`: one checkpoint list per chapter, for a
full run. Hack-specific checks are marked **[hack]**. Names are as displayed in this build,
with the retail name in brackets where it differs. Chapter order and events are from the
Tom Hayes walkthrough, version 2.0, hosted at
[Gamer's Temple](https://gamerstemple.com/guides/game-boy-advance/1580/1/dragon-ball-z-buus-fury-walkthrough).
