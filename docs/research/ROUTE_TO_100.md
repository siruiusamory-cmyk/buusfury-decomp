Generated by `tools/research/raw_remainder.py` (`python tools/research/raw_remainder.py`).
One row per INCBIN slice in `docs/research/RAW_REMAINDER.csv` (`3128` data rows), one class per
row, exactly one. The text is a pure function of the retail image and the tracked tree, so
two runs write byte-identical files. ROM `baserom.gba` sha256 `940ad5f01db4465b8877dfe739510cbf34f4ea3d390f3df13519808bc36f059e`.

**The class sum equals the gate's raw-data total: 494250 B == 494250 B (`gate.incbin_ranges()`), the
row count equals the slice count (3128 == 3128), and `--check` asserts both and writes nothing.**

Every one of those slices is assembled (P-644 supersedes P-640; K-229), and the identity
copies are the only other non-source bytes: `gate.source_bytes()` reports source 7893334 B =
94.0959 % of the image, with 1024 B of identity copies taken out on their own line.

Each row's census line, and the document that carries it, is joined in
`docs/research/RESIDUAL_INDEX.md` (`python tools/research/residual_index.py --check`).
## The priority order (a row belongs to the first class that fires)

1. `fill/padding` - a row of at least 4 B whose every byte is one value, and that value is 0x00 or 0xFF (`len(set(bytes)) == 1`)
2. `JCALG1-compressed` - the row lies inside a `build\jcalg1\gen_<start>.bin` run span (start from the file name, end = start + its size)
3. `code-without-entry` - the row is outside `docs/research/ARM_BODIES.csv` and `thumb_bodies.entries()` reports an entry whose SITE lies in the transcribed code band 0x000158..0x071758
4. `other-compressed` - `webfoot_lz.validate_retail_termination(rom, row_start)` succeeds with a PACKED kind (1 or 2) and its `packed_end` is at or before the row's end (0x4000 output ceiling)
5. `graphics` - the row lies wholly inside a measured graphics block (map block, sprite block, tilebank tiles or the tilebank palette)
6. `pointer-tables` - every 4-byte word of the row on the image's own grid is a ROM, IWRAM or EWRAM address and the row carries at least two words
7. `text/tables` - the row's exact span is a run `docs/research/TRANSCRIBED_DATA_RUNS.csv` classes as `data`
8. `audio` - the row lies wholly inside a span one of the 143 records of the two 12-byte asset directories names (`data_ptr`..`data_ptr+byte_length`; assetdir_samples.entries, the tiling K-226/K-234 measured twice)
9. `unknown` - no instrument above fired (the residual, stated at its own denominator)

## Route vocabulary, and what is NOT a route

- a byte-exact generator from a build-time extracted input (an emitter that reproduces the
  retail bytes from the tree's own extracted input),
- a decoder+encoder pair (both sides measured against the retail bytes),
- symbolic tables (a tracked table of numbers or pointers, no retail byte payload),
- NONE (no route found).

A tracked `DCB`/`DCD` dump of retail bytes is NOT a route: it is the raw-data class itself,
and this project forbids ROM bytes in any tracked file.
