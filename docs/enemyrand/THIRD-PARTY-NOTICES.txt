NO GAME CONTENT
---------------

Nothing from the commercial ROM is bundled, and nothing can be: the only data
file in the build is the ROM profile catalog, a table of addresses and hashes. The
randomizer reads the ROM the user selects and writes a separate randomized file.

KNOWN GAP - AN UNRESOLVED OWNER DECISION, INHERITED
---------------------------------------------------

Full licence TEXTS for the LGPL-licensed components (Qt, PySide6, shiboken6) are
NOT bundled, and since the release archive contains only the executable and a
README, not even this notice reaches the person who downloads it. Redistributing
an LGPL library is normally expected to carry a copy of the LGPL text and a written
offer of the corresponding source, and nothing here substitutes for either.

This gap is not new to this product. The Map Warp Randomizer's release has the
same gap and records it in `docs/warprand/THIRD-PARTY-NOTICES.txt`; this file
inherits it deliberately rather than diverging from a sibling tool for no reason,
and to change it is one decision covering both. The application is currently a
private, unlisted build. If it is to be distributed publicly, either add the
notice and the Qt/PySide6 licence texts back into the two package scripts' staged
files, or link Qt statically and comply with the LGPL that way.
